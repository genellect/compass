# 3Dページの情報設計

2026-09-13の再検討を反映。親サイトの自動ON/OFFモードを廃止し、独立した `/3d/` とする。

- 通常サイト: 現行の読みやすい本文、Hero、9セクション、フォーム導線を維持。既存操作群にPC向けの入口だけを置く。
- 3Dの入口: 人物目線、立体文字、床、近景家具、展望窓を同時に見せる。保存状態のない訪問で勝手に移動しない。
- 空間操作: 自分で歩く・見回す・扉を開く。既存CTAを施設移動に横取りしない。
- 情報: 各室の端末に現行の見出し・抜粋と元のCTA。本文パネルを開くためのカメラ移動や、全文の共通readerは使わない。
- Interactive: 研究ラボと既存の製品紹介ポスターを使う物理TV。既存紹介ページに進むCTA。
- Library: 書架と学習席からライブラリ紹介ページへ。
- Contact: 応接スペースから既存Contactフォームへ。フォームを3Dに移植しない。
- 残るエリア: 現行素材・コピー・写真を再利用し、館内案内からすべて到達可能にする。
- 閲覧補助: 館内案内から歩かずに部屋へ移動でき、各サイトを直接開くこともできる。低い画面や拡大時は現在の室内説明を安定した位置へ置く。

一般的な暗幕で空間を隠さず、案内面自体の深い青緑と白で文字のコントラストを確保する。読み上げ、フォーカス中の安定性、文字選択を残す。

実写は遠景のNASA写真として使用する。室内建築は制作したCGであり、実在するCOMPASS施設を撮影した映像、完全な360度写真、実写級品質の達成済み証明として扱わない。
