## E2E中のUI修正

- Mobileで判定カードがフォームより前に表示される指定を削除し、入力後に確認できる順序へ修正した。
- 626px幅で認証ボタンが画面外へはみ出す問題を修正し、900px以下では認証パネルを縦配置にした。
- 学部生・修士課程以外では学年・学籍番号を非表示にし、不要値を状態から削除した。
- 判定結果を承認、個別確認、対象外、登録済みに分離した。
- 結果へフォーカスを移し、判定理由と正規化学籍番号を読み上げ可能にした。
- 現行GASの5つの利用条件を省略せず表示した。

## 残る実機確認

ローカルURLに対するブラウザ保護がE2E後半で有効になったため、対象外モックへのアカウント切替と指定Mobile幅での実画面計測はブラウザでは完走していない。対象外ドメインはTypeScriptとFastAPIの共通ケースで確認済みである。Mobileの最終実機確認はCloudflare Preview Deploymentで行う。

この制約を回避するための別ブラウザや直接制御は使用していない。
